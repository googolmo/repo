Debian / Ubuntu source

APT metadata (Packages, signed InRelease) is published under this directory. .deb files 302 to Imprint GitHub Releases.

Add the APT source

Recommended on Ubuntu 24.04+, Debian 13+, and newer.

sudo mkdir -p /usr/share/keyrings
sudo curl -fsSL https://repo-cr4.pages.dev/keys/repo.gpg \
  -o /usr/share/keyrings/repo-archive-keyring.gpg
sudo chmod 644 /usr/share/keyrings/repo-archive-keyring.gpg
sudo curl -fsSL https://repo-cr4.pages.dev/ubuntu/mosumi-repo.sources \
  -o /etc/apt/sources.list.d/mosumi-repo.sources
sudo apt update
sudo apt install imprint

For the one-line sources.list format, use mosumi-repo.list instead of mosumi-repo.sources. Default suite is noble (Ubuntu 24.04). Suite resolute covers Ubuntu 26.04. Architectures: amd64 and arm64.
