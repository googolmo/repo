Debian / Ubuntu

Install the signing key, then drop in the DEB822 source file.

  1. Download the binary keyring to /usr/share/keyrings.
  2. Install ubuntu/repo.sources.
  3. Run apt update and apt install imprint.
sudo mkdir -p /usr/share/keyrings
sudo curl -fsSL https://repo-cr4.pages.dev/keys/repo.gpg \
  -o /usr/share/keyrings/repo-archive-keyring.gpg
sudo chmod 644 /usr/share/keyrings/repo-archive-keyring.gpg
sudo curl -fsSL https://repo-cr4.pages.dev/ubuntu/repo.sources \
  -o /etc/apt/sources.list.d/repo.sources
sudo apt update
sudo apt install imprint

Older APT setups can use ubuntu/repo.list instead of the .sources file. Packages lives under ubuntu/ for suites ubuntu22.04, ubuntu24.04, and ubuntu26.04 on amd64 and arm64. Each .deb 302s to its GitHub Release asset.

Arch Linux / Pacman

Import the signing key, install the repo snippet, then sync. repo.db is here; .pkg.tar.zst is fetched from GitHub Releases.

  1. Add and locally sign keys/repo.asc.
  2. Install pacman/repo.conf.
  3. Include it from /etc/pacman.conf.
  4. Run pacman -Sy imprint.
curl -fsSL https://repo-cr4.pages.dev/keys/repo.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 9DF42B7054F1CB5B
sudo curl -fsSL https://repo-cr4.pages.dev/pacman/repo.conf \
  -o /etc/pacman.d/repo
echo -e '\nInclude = /etc/pacman.d/repo' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy imprint

Signed repo.db is under x86_64 and aarch64.
